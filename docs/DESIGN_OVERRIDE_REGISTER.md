# Studio design overrides and reference limits

| Requirement | Decision used for the Studio |
| --- | --- |
| “Preserve the approved brand, Maya identity and explicit owner additions” (current release instruction) | Keep branded typography, Maya experience selection and the additional render styles. The source and tool-specific settings remain the primary workflow. |
| “In the studio remove the slider in the beginning. give that as an option to choose from” (owner feedback) | Show a single image initially. A user can explicitly compare an illustrative pair or a saved source and output. |
| “Remove the footer named today and reimagined” (owner feedback) | Omit the prototype's image-footer captions. Preserve accessible descriptions of the two images. |
| “Use only MNML v4.5 Fast” and “Keep billing and unverified optional services disabled” (release scope) | Only the approved tester campaign may submit after dependency verification. No prototype wallet amount, estimate or expiry is authoritative. |
| “Norwegian Bokmål default with English top-right toggle, light/dark/system theme” (project instructions) | Translate and adapt the English/dark reference. A translated layout or real-device experience requires its own evidence. |
| Private media intake | Multipart uploads accept JPEG, PNG and WebP up to 4 MiB per image. The prototype's 20 MB label exceeds the implemented transport limit. Private object references require ownership. |
| Source conflicts | Hardscape and Outdoor remain separate despite the shared FigJam section. Seasonal sample labels describe the example only. Gallery and social destinations require independent consent and editorial approval. |

The original references and journey node IDs are in the [designer findings](release-execution/reference-evidence/STUDIO_17_TOOL_PARITY_FINDINGS.md) and [journey matrix](JOURNEY_PARITY_MATRIX.md). A local overlay or photo adjustment is evidence of browser behavior only. Provider support for exact geometry, pixel masks, compositing, video and batch generation requires its own tests.
