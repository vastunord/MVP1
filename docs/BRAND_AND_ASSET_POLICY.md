# Brand and asset policy

The [official guide](../assets/brand/Brand%20Guidelines%20Document.pdf) supplies the logo configurations on pages 14–18, six palette swatches on page 19, the type family on page 20 and usage examples on pages 21–34. Preserve the artwork and its proportions. Take colors from the source artwork. Load Zalando Sans Expanded from its official Google Fonts delivery endpoints. Keep font binaries out of the repository and application distributions. The [brand parity record](BRAND_PARITY.md) identifies the approved artwork, font provenance and checks.

Approved workflow for new visual assets: (1) preserve existing owned source (2) use owner-provided open Google Drive/Photos library, after verifying ownership and permission (3) use inbuilt/native image or video creation capability if actually available and authorized (4) request owner assets when missing. Never install external image generation or stock plugins, or reuse competitor IP without permission.

Marketing: editorial, warm, architectural; Studio: restrained, readable, immersive dark-first if it matches approved design; both share tokens. Use realistic spatial arrangements; preserve user's original photo and distinguish AI concepts from real construction guarantees.

**Replace every Studio tool visual via a tracked asset manifest**; include source URL, license, matched tool ID, crops for desktop/mobile, alt text, review and deploy status. Never assume public link means licensed stock. Optimize media size; generate multiple responsive sizes without altering image meaning.
