**Persistence.** Normal settings use the existing versioned Maya draft. The placement study can retain numeric positions, sizes, notes and owned object asset IDs in the signed-in user's project/tool/source-scoped session storage. Project asset choices are rechecked through the authorized project listing. Device-only image URLs and pixels do not survive reload. Pin notes are not server-side project revisions.

**Source inputs.** The designer selected-source editor offers additional views. The candidate uses one active source per render and its existing optional reference slots where applicable. A reference image has a distinct meaning from an alternate source view. Paid multi-source generation and batch export remain unverified.

**Prototype result states.** After selecting the public Back garden sample, each of these ten designer editors enabled its primary action and reached a simulated Version 1 with Original, v1 and Download controls. Object Placement first required a position. The read-only browser blocked outgoing writes and provider submissions. [Per-tool observations](reference/simulated-photo-tool-journeys.json).

**Designer failure path.** With the prototype’s D-5 Generation failed state selected, Sky showed Finding the skyline and an enabled Cancel action, then That did not generate, a two-second retry countdown labelled attempt 1 of 3, and Stop. This source simulation used only the built-in sample and blocked external writes. Its automatic retry and charge messages do not authorize a further paid MNML submission. No real-provider failure or refund was verified.

**Local browser results.** Five designer-photo cases passed, including distinct object/source handling, material and decor pins, tidy-mode restoration, pool mode changes, winter settings, screen-only guides and preview controls. The PNG case verified changed canvas pixels, reset and a browser download. Complementary Maya, mobile keyboard/overlay and Studio metadata checks passed in a 40-test run. Expanding the pool cards changed their accessible names; the pool regression now locates the descriptive cards and retains its original spillover-reset assertions.

**Final candidate.** On application revision `672577a`, the selected-source requirement, pixel changes, reset and PNG download passed. One initial run could not locate the perspective guide control within five seconds. The subsequent HTTP check returned 200 with the correct title and control in the body. With explicit route status and heading assertions added, all five focused cases passed against the same build (`L4YoJgoYagOnA2qvtOkdc`). The initial missing-control condition was not reproduced.
