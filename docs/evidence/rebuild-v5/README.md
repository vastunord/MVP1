# Responsive UI comparisons

Playwright captured the Vastu Nord Next.js routes at four viewport widths, each with a 900 px initial height, Norwegian and the light theme. Each image places the full baseline page on the left and the rebuilt page on the right. The desktop captures are scaled proportionally to fit side by side. Empty space below a shorter page marks its end. Some new workspace routes showed the missing-page view before this release. The frames compare application versions. Verification against the approved marketing Figma frames is pending.

The left panels show demonstration release `2eaf94b`. The right panels show release `c71034b` on the [public Vastu Nord demonstration](https://vastunord-web.vercel.app/). After release, all 120 route and viewport combinations returned HTTP 200. Every visible image loaded and each page fit its viewport horizontally. The mobile Fjord study cover fits within its content column, and the desktop Studio library uses four cards per row at 1440 px.
